# KRDS 아이콘 토큰 매핑

> 공통 스펙: [`framework/specs/tokens/icon.md`](../../specs/tokens/icon.md)
> 소스: [KRDS 스타일 가이드 — 아이콘](https://www.krds.go.kr/html/site/style/style_06.html)

## 1. "하나의 라이브러리" → KRDS 시스템 아이콘 세트

공통 스펙의 핵심 규칙("하나의 아이콘 라이브러리만 사용")을 KRDS는 **시스템 아이콘 통일**이라는 이름으로 그대로 요구한다 — 모든 기관이 동일한 시각 언어를 쓰도록 강제해서 사용자 학습 비용을 줄이는 목적. 실제 SVG 세트는 `krds-uiux` 패키지에 포함되어 있어 어댑터가 그대로 참조 가능.

- 단, **브랜드 아이덴티티용 일반 아이콘**은 기관별로 다르게 써도 무방 — "시스템 아이콘만 통일, 장식용 아이콘은 자유"로 공통 스펙보다 한 단계 세밀하게 구분한다.

## 2. 사이즈 → 24px 기준, 4/8px 배수

| 크기 | 용도 |
| --- | --- |
| 16px | 축소 표기 |
| 20px | 보조 |
| **24px** | 기본(대부분의 인터페이스) |
| 32px | 강조 |
| 40px | 넓은 공간, 강조 |

## 3. 두께 → 1.6px (24px 기준)

- 24×24 아이콘 기준 스트로크 두께 **1.6px** (권장 범위 1.5~2px).
- 비율 유지로 다른 크기에 스케일링.

## 4. 모서리 둥글기 → 매우 제한적 (0.8px 수준)

- Join(모서리 처리) 설정이 대략 `radius 0.8px`과 동일.
- 24px 아이콘에서 radius 5px 이상 사용 시 형태가 깨지지 않는지 반드시 확인 — 아이콘은 [radius.md](./radius.md)의 Xsmall(2px) 체계와도 다른, 훨씬 미세한 별도 규칙임에 주의.

## 5. 색상 → 텍스트와 동일한 대비 기준

- 기본 모드: 인접 색상과 최소 **3:1**(매직넘버 40).
- 선명한 화면 모드: **7:1**(매직넘버 70).
- 아이콘 색상은 [colors.md](./colors.md)의 매직넘버 규칙을 그대로 상속 — 별도 아이콘 전용 팔레트를 만들지 않는다.

## 6. 세부 규칙 (공통 스펙에는 없는 KRDS 고유 항목)

- **확장자**: SVG 고정 (벡터, CSS 스타일링 가능, 경량).
- **키라인(Keyline)**: 24×24 기준 1000% 스케일 키라인으로 정사각/원형/직사각 아이콘의 시각적 면적을 통일.
- **End cap**: 선 끝 모양은 둥글게(round) 통일.
- **Off slash**: 금지/꺼짐 표시 사선은 좌상단→우하단 방향으로 통일, 여백은 두께의 1/2(0.8px).
- **Stack(중첩 아이콘)**: 좌→우 순서로 쌓고 여백 1.6px 고정.
- **시점**: Perspective 금지, Front view만 사용.
- **타입**: Line / Fill 두 타입을 혼용하지 않고 구분해서 사용.

## 7. 라이브러리에 없는 아이콘이 필요할 때

공통 스펙의 대응 방법(AI 생성 / 변환 도구 / 배경 제거)을 그대로 적용하되, KRDS 맥락에서는 신규 아이콘도 위 키라인·두께·둥글기 규칙을 반드시 따라야 "시스템 아이콘"으로 인정된다는 점이 다르다.
