# 이미지 / 모달 / 텍스트 말줄임 패턴

> 출처: `talk/script.md` 슬라이드 28~29. 포맷별 비율과 세로형/가로형 소재 분리 규칙은 대본에는 없으나, `examples/vite-shadcn-demo/doc/design-system/{고정,변동}/media.md`가 실제 발표 시각자료 제작 과정에서 정리해둔 규칙을 일반화해 승격했다.

## 1. 이미지

- 화면을 꽉 채우는 이미지는 가로/세로 중 한쪽이 필연적으로 잘린다 — 어느 부분이 잘릴지 미리 고려하고 이미지를 배치한다.
- 기본 원칙: **가로 100% 기준 + 세로 스크롤**.

## 2. 모달

- 너비: 디바이스 너비의 **최대 85%**.
- 내부 콘텐츠가 길어지면 모달 내부에 스크롤을 추가한다.
- 기본 정렬: 가운데.

## 3. 텍스트 말줄임

- 배너/카드형 텍스트는 **3줄까지만** 노출하고 나머지는 말줄임표(ellipsis) 처리한다.
- Tailwind는 `line-clamp-3` 유틸리티로 지원한다.

## 4. 세로형·가로형 소재는 따로 만든다

- 풀스크린·모달·스티커배너처럼 화면 형태에 맞춰 노출되는 소재는 **세로형과 가로형을 별도로 제작**한다.
- 한 장을 회전하거나 한쪽만 늘려서 재사용하지 않는다 — 비율이 다른 화면에 억지로 맞추면 §1의 크롭 문제가 그대로 재발한다.

## 5. 형식별 비율

포맷마다 지켜야 할 세로/가로 비율을 미리 정해두면, 매번 "이 배너는 몇 대 몇으로 만들지"를 새로 판단하지 않아도 된다.

| 포맷 | 세로 | 가로 |
| --- | --- | --- |
| 풀 스크린 (이미지) | 9:16 | 16:9 |
| 풀 스크린 (스크롤) | 세로 제한 없음(9:16 또는 그보다 긴 비율) | 1:1 또는 세로로 긴 비율 |
| 풀 스크린 (이미지+텍스트) | 9:8 | 32:9 |
| 모달 (이미지) | 2:3 (기본 1:1) | 3:2 (기본 1:1) |
| 모달 (이미지+텍스트) | 29:10 | 29:10 |
| 스티커배너 (이미지+텍스트) | 1:1 | 1:1 |

## 토큰화

```css
:root {
  --media-modal-max-width: 85%; /* §2 */
  --media-text-line-clamp: 3; /* §3 */
}
```

비율(§5)은 CSS 변수가 아니라 이미지 제작 단계에서 지키는 규칙이라, 소재 제작 체크리스트나 디자인 툴의 프레임 프리셋으로 관리한다.
