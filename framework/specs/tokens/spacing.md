# 간격 토큰 스펙 (Spacing)

> 출처: `talk/script.md` 슬라이드 25, 27.

## 기본 단위

- 기본 단위는 **8px**. 필요한 경우에만 **4px** 단위까지 허용한다 (8의 절반 이하로는 내려가지 않는다).
- 임의의 값(예: 13px, 22px)은 사용하지 않는다.

```
space-1: 4px   (예외적 허용)
space-2: 8px   (기본 단위)
space-3: 16px
space-4: 24px
space-5: 32px
space-6: 40px
space-7: 48px
```

## Depth 기반 간격

요소 간 간격은 **Depth(중첩 단계)** 별로 구분해서 설정한다 — 같은 depth의 형제 요소는 같은 간격 토큰을 쓰고, depth가 깊어질수록(부모→자식) 더 작은 간격 토큰으로 좁혀가는 식으로 일관성을 유지한다.

## 모바일 간격

모바일(좁은 화면)에서는 간격을 화면 크기에 따라 유동적으로 바꾸기보다 **고정값**으로 통일해서 사용하는 경우가 많다 (예: 섹션 간 항상 `space-4`(24px)).
