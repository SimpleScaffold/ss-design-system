# 간격 토큰 스펙 (Spacing)

> 출처: `talk/script.md` 슬라이드 25, 27. Depth 스케일 설계법과 브레이크포인트 정합 규칙은 대본에는 없으나, `examples/vite-shadcn-demo/doc/design-system/변동/spacing.md`, `examples/shadcn-case/spacing-grid.md`, `framework/adapters/ant-design/layout.md`가 각자 정리해둔 실제 사례에서 공통되는 원칙만 일반화해 승격했다.

## 기본 단위

- 기본 단위는 **8px**. 필요한 경우에만 **4px** 단위까지 허용한다 (8의 절반 이하로는 내려가지 않는다).
- 임의의 값(예: 13px, 22px)은 사용하지 않는다.

```
space-1: 4px   (예외적 허용)
space-2: 8px   (기본 단위)
space-3: 16px
space-4: 24px
space-5: 32px
space-6: 40px
space-7: 48px
```

## Depth 기반 간격

요소 간 간격은 **Depth(중첩 단계)** 별로 구분해서 설정한다 — 같은 depth의 형제 요소는 같은 간격 토큰을 쓰고, depth가 깊어질수록(부모→자식) 더 작은 간격 토큰으로 좁혀가는 식으로 일관성을 유지한다.

## Depth 스케일 설계

- Depth는 보통 3~4단계(0~3)면 충분하다 — 제목 위계(예: 페이지 제목 → 섹션 제목 → 카드 제목 → 본문)가 깊어질수록 그 사이 간격도 좁아지도록 설계한다.
- **가장 깊은 단계는 화면 크기에 따라 다시 늘리지 않는다** — 예를 들어 Depth 0(페이지 제목 → 본문)은 데스크톱에서 더 크게 벌릴 수 있어도, Depth 3(가장 좁은 형제 간격)은 화면이 커져도 그대로 유지하는 편이 안전하다. 가장 좁은 간격까지 반응형으로 벌리면 화면이 커질수록 콘텐츠 사이 관계가 오히려 느슨해 보인다.
- 각 Depth 값은 8px(또는 4px) 배수를 벗어나지 않는다 — 기본 단위 규칙은 Depth 스케일에도 그대로 적용된다.

## 브레이크포인트와 같은 기준점을 쓴다

- 간격이 화면 크기에 따라 달라진다면(§Depth 스케일의 반응형 확장), 그 전환 지점은 `tokens/layout.md`의 반응형 기준 해상도와 **같은 값**을 써야 한다.
- 간격과 컬럼 수가 서로 다른 브레이크포인트에서 바뀌면, 화면을 늘리다가 컬럼 배치는 그대로인데 간격만 갑자기 벌어지는(또는 그 반대) 어긋난 지점이 생긴다.

## 그리드 단위 선택 — 8px 기본, 4px 예외

- 이 스펙의 기본 권장값은 8px 그리드(§기본 단위)지만, 실제 프로젝트가 4px을 기본 그리드로 채택하는 경우도 있다 — 더 촘촘한 밀도(리스트형 화면, 데이터 테이블)가 필요할 때다.
- 4px을 기본으로 택하면 "8px 배수만 허용"이 아니라 "4px 배수는 전부 허용"이 되어 선택지가 두 배로 늘어난다 — 그만큼 팀 안에서 값이 흩어지기 쉬워진다는 대가를 감수하는 결정이다.
- 어느 쪽을 택하든 **프로젝트 전체에서 하나의 그리드 단위로 통일**하고, `validation/accessibility-checklist.md` §5의 "임의 값 없음" 기준을 그 그리드에 맞춰 적용한다.

## 모바일 간격

모바일(좁은 화면)에서는 간격을 화면 크기에 따라 유동적으로 바꾸기보다 **고정값**으로 통일해서 사용하는 경우가 많다 (예: 섹션 간 항상 `space-4`(24px)).

## 토큰화

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 16px;
  --space-4: 24px;
  --space-5: 32px;
  --space-6: 40px;
  --space-7: 48px;

  /* Depth 스케일 — 반응형 확장은 가장 깊은 단계(depth-3)를 제외한 단계만 */
  --space-depth-0: 64px;
  --space-depth-1: 40px;
  --space-depth-2: 32px;
  --space-depth-3: 24px;
}

@media (min-width: 1280px) { /* tokens/layout.md의 Desktop 기준과 동일한 지점 */
  :root {
    --space-depth-0: 80px;
    --space-depth-1: 64px;
    --space-depth-2: 40px;
    /* depth-3은 스케일하지 않는다 */
  }
}
```
