# script-10min

FEConf 리뷰어 피드백 반영 초안 — 10분 세션 기준 15장 재구성.

- 기존 `talk/script.md`(33장, 원본 대본)는 건드리지 않았다. 이 폴더는 별도 초안이다.
- 피드백 핵심: 슬라이드 4~30이 디자인 원칙 설명에 치우쳐 "디자인 입문 강의"처럼 보인다는 지적 → 규칙 설명 비중을 줄이고, FE 개발자가 왜 규칙을 만들게 됐는지(배경)와 그 규칙을 코드·AI로 어떻게 연결했는지(전환)의 비중을 키운다.
- 대본에서 덜어낸 세부 규칙(투명도 단계, Radius/폰트/아이콘 상세, 레이아웃·반응형·모바일 간격, 이미지/모달/텍스트 말줄임 등)은 삭제가 아니라 `framework/specs/`에 그대로 남아 있으며, 슬라이드 9·14에서 Repository로 안내한다.
