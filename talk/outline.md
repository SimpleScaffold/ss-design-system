# 발표 개요 — AI와 똥손 개발자를 위한 디자인 가이드

> 전체 대본: [`talk/script.md`](./script.md) (슬라이드 1~33)

## 스토리라인

1. **문제 제기** (1~3) — 개발자와 AI 둘 다 디자인 "감각"이 부족하다 → 감각 대신 규칙으로 공식화하자.
2. **색상 공식** (4~17) — 60-30-10 비율 → 대기업 사례(토스/네이버/당근) → Primary 선정 → 팔레트 생성 → 대비 기준 → 상태별 색상 → 배경 레이어 → 보조 팔레트 → 시스템/컴포넌트 색상 → 토큰화 → (심화) 투명도 단계.
3. **Radius** (18) — 하나의 값으로 통일.
4. **타이포그래피** (19~20) — 폰트 소스, 다국어, rem 기준값, 이모지 주의, 토큰화.
5. **아이콘** (21) — 라이브러리 하나로 통일.
6. **레이아웃/그리드** (22~27) — 최대 너비, Gutter/Column, 반응형 컬럼 수, 사이드바, 간격 단위, 반응형 기준 해상도.
7. **이미지/모달/텍스트** (28~29) — 크롭 기준, 모달 너비, 3줄 말줄임.
8. **종합 — 디자인 시스템** (30) — 지금까지의 규칙들이 모여 하나의 디자인 시스템이 된다.
9. **AI에게 전달하기** (31) — 규칙을 Markdown 프롬프트로 정리 → Stitch/Claude Design 등에 입력 → MCP·명령 정확도 상승.
10. **참고 자료** (32) — Repository 안내.
11. **마무리 메시지** (33) — AI 시대 개발자에게 필요한 건 "잘 그리는 능력"이 아니라 "잘 정의하는 능력".

## 핵심 메시지 (한 줄)

> 디자인 감각을 규칙으로 바꾸고, 그 규칙을 시스템으로 만들고, AI가 이해할 수 있게 전달하라.
