# 미디어 패턴 — 이 프로젝트가 채운 값

> 규칙: [`../고정/media.md`](../고정/media.md) · 실제 코드: [`../../src/App.tsx`](../../src/App.tsx), [`../../src/components/ui/dialog.tsx`](../../src/components/ui/dialog.tsx)

## 이미지 — 가로 100%

외부 이미지 의존 없이 로컬 인라인 SVG로 데모했다("미디어 패턴" 섹션의 "가로 100% 이미지" 카드) — 6팔레트 중 5개(primary/destructive/success/warning/info)의 실제 semantic 토큰(`var(--primary)` 등)을 색 스와치로 그려, `--surface-recessed` 배경 위에 `width: 100%`로 채운다. 실제 프로덕션 이미지라면 `<img className="w-full h-auto">` + 컨테이너 `overflow-y-auto`로 같은 원칙을 적용한다.

## 텍스트 말줄임 — line-clamp-3

"3줄 말줄임" 카드가 실제 적용 예시다. 문단 길이와 무관하게 카드 높이가 늘어나지 않고, 3번째 줄 끝에서 말줄임표로 잘린다.

```tsx
<p className="line-clamp-3 text-body-2 text-muted-foreground">...</p>
```

## 모달 너비 — 최대 85%, 가운데 정렬, 내부 스크롤

`src/components/ui/dialog.tsx`의 `DialogContent`를 shadcn 기본값(`max-w-[calc(100%-2rem)] sm:max-w-sm`, 고정 폭 위주)에서 아래로 고쳤다.

```
w-[85vw] max-w-md          /* 디바이스 너비의 최대 85% */
max-h-[85vh] overflow-y-auto  /* 내부 콘텐츠가 길어지면 내부 스크롤 */
top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2  /* 가운데 정렬 */
```

배경은 `--surface-modal`(표면 3단계), 그림자는 `--elevation-3`을 쓴다 — 자세한 값은 [`elevation.md`](./elevation.md) 참고. 딤드(배경 어둡게)는 `DialogOverlay`에서 `bg-black/70`으로 통일했다(elevation.md §5).

## 풀스크린 · 모달 · 스티커배너 소재 규격

세로형·가로형 각각 최소~최대 px. 비율은 [`../고정/media.md`](../고정/media.md) 4·5번.

| 구분 | 세로형 (px) | 가로형 (px) |
| --- | --- | --- |
| 풀 스크린 (이미지) | 540×960 ~ 1080×1920 (9:16) | 960×540 ~ 1920×1080 (16:9) |
| 풀 스크린 (스크롤) | 가로 540~1080, 세로 제한 없음 (9:16 또는 세로로 긴 비율) | 가로 540~1080, 세로 제한 없음 (1:1 또는 세로로 긴 비율) |
| 풀 스크린 (이미지+텍스트) | 540×480 ~ 1080×960 (9:8) | 960×270 ~ 1920×540 (32:9) |
| 모달 (이미지) | 600×600 ~ 1200×1800 (1:1, 2:3 추천) | 600×600 ~ 1800×1200 (1:1, 3:2 추천) |
| 모달 (이미지+텍스트) | 725×250 ~ 1450×500 (29:10) | 725×250 ~ 1450×500 (29:10) |
| 스티커배너 (이미지+텍스트) | 50×50 ~ 150×150 (1:1) | 50×50 ~ 150×150 (1:1) |

이 데모 화면에는 위 규격의 실제 광고 소재를 넣지 않았다. 풀스크린·모달·스티커배너를 만들 때 이 범위를 벗어난 임의 해상도를 쓰지 않는다.
