# 아이콘 — 고정 규칙

> 출처: [`framework/specs/tokens/icon.md`](../../../../framework/specs/tokens/icon.md).

1. **하나의 아이콘 라이브러리만 선택해서 사용한다.** 여러 라이브러리를 함께 쓰면 라이브러리별로 Live Area(아이콘 주변 여백)가 달라 통일감이 떨어지고, 아이콘마다 크기를 개별 보정해야 하는 문제가 생긴다.
2. **라이브러리에 없는 아이콘이 필요할 때**는 다음 순서로 해결한다: ① AI로 직접 생성 ② 이미지를 favicon/아이콘 형태로 변환하는 도구 사용 ③ 배경 제거(누끼) 사이트 활용.
