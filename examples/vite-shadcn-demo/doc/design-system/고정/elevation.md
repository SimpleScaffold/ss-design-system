# 엘리베이션 — 고정 규칙

> 출처: [`framework/specs/tokens/elevation.md`](../../../../framework/specs/tokens/elevation.md). `talk/script.md`에는 없는 내용 — KRDS 스타일 가이드 학습 과정에서 발견해 공통 스펙으로 승격한 개념.

1. **표현 수단은 그림자·표면색·딤드·경계선 4가지다.** 그림자(Shadow)는 단계가 높을수록 offset/blur/opacity를 키우고, 표면 색상은 [`colors.md`](./colors.md) §6 배경 레이어와 같은 개념이며, 딤드(Dim)는 아래 층 전체를 어둡게 해 위 층에 시선을 모으고(모달 등), 경계선(Border)은 그림자를 쓰기 애매할 때(고대비 모드 등) 대신 쓴다.
2. **처음엔 최소 단계로 시작한다.** `base(0) → raised(1) → overlay(2)` 3단계면 대부분의 서비스에 충분하다. 필요가 커지면 `-1 ~ +4`(6단계)까지 늘리되, 단계마다 대응하는 컴포넌트를 명시적으로 고정해서 오남용을 막는다.
3. **다크/고대비 모드는 그림자만으로 층을 구분하기 어렵다.** 불투명도를 더 진하게 올리거나, 그림자 대신 보더·표면색 대비로 층을 구분하는 쪽을 함께 쓴다. 표면색은 "위로 쌓일수록 더 밝아지는" 방향으로 조정하는 경우가 많다.
4. **딤드는 하나로 통일한다.** 모달/바텀시트처럼 최상위 레이어를 띄울 때 그 아래 전체 화면에 반투명 검정(예: `black/70~75%`)을 깔되, 컴포넌트마다 다른 값을 쓰지 않는다.
