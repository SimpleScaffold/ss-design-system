# 검증 — 고정 규칙

> 출처: [`framework/specs/validation/accessibility-checklist.md`](../../../../framework/specs/validation/accessibility-checklist.md). 여러 토큰 스펙에 흩어진 접근성·일관성 규칙을 하나의 체크리스트로 모은 것 — "무엇을 규칙으로 정하는지"가 아니라 "그 규칙을 실제로 지켰는지 어떻게 확인하는지"를 다룬다.

1. **색상**: 본문 대비 4.5:1 이상(WCAG AA), 고대비 모드 본문 7:1·헤딩 4.5:1 이상, 상태를 색상만으로 표현하지 않기(아이콘/텍스트 병행), 팔레트에 없는 hex 하드코딩 여부.
2. **타이포그래피**: 줄간격 본문 기준 최소 150%, 프로젝트 전체 폰트 1개만 사용, 지원 언어 전부 커버.
3. **상태·상호작용**: Default→Hover→Pressed가 팔레트 인접 레벨만 이동했는지(건너뛰지 않기), Focus-visible에 비색상 단서가 있는지, Disabled도 최소 대비를 유지하는지.
4. **레이아웃·간격**: 8px 단위(예외 4px) 외 임의 값이 없는지, 단일 radius 기준 외 값이 없는지, 요소가 Column 경계에서 시작·종료하는지.
5. **엘리베이션**: 정의한 단계 밖의 임의 그림자 값이 없는지, 다크/고대비 모드에서 그림자 대신 보더·표면색 대비로 층을 구분하는지.
6. **실행 순서**: 색상 대비 → 팔레트 이탈 값 스캔 → 타이포 일관성 → 상태·상호작용 → 간격/Radius → 엘리베이션. 빠르게 훑을 때는 대비·팔레트 이탈·Focus-visible 세 가지를 우선한다.
