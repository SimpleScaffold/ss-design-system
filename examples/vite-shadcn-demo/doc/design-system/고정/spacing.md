# 간격 — 고정 규칙

> 출처: [`framework/specs/tokens/spacing.md`](../../../../framework/specs/tokens/spacing.md).

1. **기본 단위는 8px.** 4px는 예외적으로만 허용하고, 8의 절반 이하로는 내려가지 않는다.
2. **임의의 값을 쓰지 않는다.** 13px, 22px처럼 8px 배수(또는 예외 4px)에서 벗어난 값은 쓰지 않는다.
3. **Depth 별로 간격을 구분한다.** 같은 depth(형제 요소)는 같은 간격 토큰을, depth가 깊어질수록(부모→자식) 더 작은 간격 토큰을 쓴다.
4. **모바일은 고정값으로 통일한다.** 화면 크기에 따라 유동적으로 바꾸기보다, 섹션 간 간격처럼 반복되는 값은 하나로 고정한다. 단, Depth별 간격 자체는 브레이크포인트에 따라(예: Desktop이 Mobile보다 더 큰 값을) 다시 통일해서 쓸 수 있다 — "화면 크기에 따라 매번 다른 값"과 "브레이크포인트별로 재고정된 하나의 값"은 다르다.
