# 미디어 패턴 — 고정 규칙

> 출처: [`framework/specs/patterns/media.md`](../../../../framework/specs/patterns/media.md).

1. **이미지는 가로 100% 기준 + 세로 스크롤이 기본 원칙이다.** 화면을 꽉 채우는 이미지는 가로/세로 중 한쪽이 필연적으로 잘리므로, 어느 부분이 잘릴지 미리 고려해 배치한다.
2. **모달 너비는 디바이스 너비의 최대 85%다.** 내부 콘텐츠가 길어지면 모달 내부에 스크롤을 추가하고, 기본 정렬은 가운데다.
3. **배너·카드형 텍스트는 3줄까지만 노출한다.** 나머지는 말줄임표(ellipsis) 처리하며, Tailwind는 `line-clamp-3` 유틸리티로 지원한다.
4. **풀스크린·모달·스티커배너 소재는 세로형과 가로형을 따로 만든다.** 한 장을 회전하거나 한쪽만 늘려 쓰지 않는다. 실제 px 범위는 [`../변동/media.md`](../변동/media.md).
5. **형식별 비율을 지킨다.** 풀 스크린(이미지) 세로 9:16 · 가로 16:9, 풀 스크린(스크롤)은 세로 제한 없음(세로는 9:16 또는 그보다 긴 비율, 가로는 1:1 또는 세로로 긴 비율), 풀 스크린(이미지+텍스트) 세로 9:8 · 가로 32:9, 모달(이미지)은 1:1을 기본으로 세로는 2:3 · 가로는 3:2를 추천, 모달(이미지+텍스트)과 스티커배너(이미지+텍스트)는 세로·가로 동일 비율(각각 29:10, 1:1).
