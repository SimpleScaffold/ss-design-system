# Radius — 고정 규칙

> 출처: [`framework/specs/tokens/radius.md`](../../../../framework/specs/tokens/radius.md).

1. **하나의 값으로 통일한다.** 카드·버튼·입력창 등 모든 컴포넌트가 같은 `--radius` 하나를 공유한다.
2. **단계가 필요해지면 배수 관계로 늘린다.** `sm/md/lg/xl` 등을 추가하더라도 기준값(`--radius`)에 대한 배수(`calc(var(--radius) * 0.6)` 등)로 파생하고, 서로 무관한 값을 새로 정하지 않는다.
3. **감으로 고르지 않는다.** 인상(각짐/둥긂)에 따라 값 범위만 다를 뿐, 프로젝트 안에서는 항상 같은 하나의 값이다.
