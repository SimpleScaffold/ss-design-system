# research

참고자료 수집·요약에 사용한 프롬프트 모음. 상위 인덱스는 [`../README.md`](../README.md).

- [`design-system-reference.md`](./design-system-reference.md) — 시스템 하나의 디자인 철학·공식 소스를 `references/design-systems/<system>/README.md` 형식으로 깊게 정리하는 프롬프트. 새 디자인 시스템 하나를 처음 조사할 때 쓴다.
- [`case-study-collection.md`](./case-study-collection.md) — 사례/아티클/도구 여러 건을 큐레이션해 목록형 문서(`references/ai-agent-workflows/`, `conference-talks/` 등)로 정리하는 프롬프트. 확신 있는 항목을 여러 개 모아야 할 때 쓴다.

## 언제 어느 것을 쓰나

한 시스템의 철학·근거를 깊게 파고들 때는 `design-system-reference.md`, 여러 개의 독립된 사례·링크를 큐레이션할 때는 `case-study-collection.md`를 쓴다. 조사 결과 그 시스템의 실제 토큰 값까지 필요해지면 `../framework/adapter-authoring.md`로 넘어간다.
